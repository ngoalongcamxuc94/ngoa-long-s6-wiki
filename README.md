# Ngọa Long S6 Wiki v2.0-beta1

## Nội dung chính

- Học viện Ngọa Long – Giai đoạn 1 với 4 bài hướng dẫn cơ bản.
- Giao diện bài học thu gọn/mở rộng, phù hợp cho người mới.
- Hướng dẫn đăng ký, đăng nhập bằng Coowon và cho phép Flash chạy.
- Hướng dẫn thiết lập tăng tốc Coowon, khuyến nghị sử dụng mức x5.
- Bổ sung hướng dẫn Auto: chọn trình duyệt, lấy tọa độ gốc bằng F9, Vượt Tháp Thí Luyện, Tự vượt Phó Bản và các chức năng khác.

## Cách sử dụng

Mở file `index.html` bằng trình duyệt. Khi đưa website lên hosting, tải toàn bộ thư mục lên để các hình ảnh và tài nguyên hoạt động đầy đủ.
